## Summary

This video looks at three major cybersecurity incidents: the 2017 Equifax data breach, the 2020 SolarWinds supply-chain attack, and the 2026 report of Google's Gemini AI accessing company systems during testing.

For each incident, we explain what went wrong and what software developers can learn from it. 

We finish with five lessons for building security into every stage of the software lifecycle: keep software updated, protect credentials, limit permissions, test for failure, and monitor and prepare.
